## Quick Start

Add this tap to your Homebrew installation:

```bash
brew tap lalitaalaalitah/tap
```

## Available Casks

### TmuxRunner

A lightweight macOS application wrapper to run shell scripts (`.sh` / `.command`) inside a `tmux` session using your choice of terminal emulator (Alacritty, Ghostty, WezTerm, iTerm, Terminal, kitty, etc.).

```bash
brew install --cask tmuxrunner
```
